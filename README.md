# 👗 UM Fabrics Website

**UM Fabrics** is a modern, responsive clothing and fabrics e-commerce website built using **HTML, CSS, and JavaScript**.
It is designed to showcase products for Men, Women, and Children with a clean layout, interactive features, and smooth animations.

---

## 🚀 Features

✅ Responsive and mobile-friendly design
✅ Clean and modern UI
✅ Product categories: Men, Women, Children
✅ Product cards with images, price, and description
✅ Add to Cart functionality using JavaScript
✅ Search and filter products
✅ Product detail modal or page
✅ Smooth hover effects and CSS animations
✅ Header, Category sections, Cart, About, Contact, and Footer sections
✅ Luxury e-commerce theme

---

## 💻 Technologies Used

* HTML5
* CSS3

* Google Fonts
* Font Awesome Icons

## 🛠️ How To Run

1. Clone the repository:

```
git clone https://github.com/your-username/um-fabrics.git
```

2. Navigate to the project folder:

```
cd um-fabrics
```

3. Open the website:

Open `index.html` in your browser (or use VS Code Live Server for live preview).
